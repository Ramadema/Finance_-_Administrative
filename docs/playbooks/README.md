# Playbooks

Tareas que ya se hicieron y se van a volver a hacer, escritas como pasos. Si
saliste a buscar "cómo era esto" por segunda vez, va acá.

| Playbook | Cuándo |
|---|---|
| [`agregar-una-metrica.md`](agregar-una-metrica.md) | Un número o gráfico nuevo sobre los movimientos |
| [`agregar-una-seccion.md`](agregar-una-seccion.md) | Una pantalla nueva en el menú |
| [`agregar-un-banco.md`](agregar-un-banco.md) | Otro banco, u otro export del mismo |
| [`tocar-la-base.md`](tocar-la-base.md) | Cambiar el esquema o migrar datos guardados |
| [`migrar-un-modulo.md`](migrar-un-modulo.md) | Pasar un dominio a la estructura por módulos |

Ninguno reemplaza a [`../../AGENTS.md`](../../AGENTS.md): los invariantes de
plata valen en todos.
